# Code Review Agent

Use this skill when analyzing pull requests, reviewing code diffs, verifying safety invariants, and recommending refactorings.

## Rules
1. Check for uncaught runtime errors and memory leaks.
2. Ensure test coverage for changed logic.
3. Validate API contract compatibility.
