測試指標說明
信心指數 (Confidence Score)

根據使用者查詢 (Query) 的語意特徵與 Skill 描述關鍵詞之交集計算出的機率值。門檻值為 35%：大於等於 35% 判定為觸發 (Triggered)，小於 35% 判定為抑制 (Suppressed)。

產出品質 (Output Quality)

不僅檢驗是否觸發，更評估 Agent 調用該 Skill 後產出內容的格式合規度、參數準確度 (無幻覺) 與步驟完整性 (0-100 分)。

逐測案 Token 消耗 (Case Token Breakdown)

分別量測每個測案的 Prompt Tokens (輸入含 Skill Context) 與 Completion Tokens (推論輸出)，以掌握真實資源開銷與節省效益。
